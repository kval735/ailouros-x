Autonomy is earned incrementally. Move right only when evidence supports it.

The autonomy ladder

Each stage requires evidence from the previous stage before expanding agent authority.

Stage 01
Draft only
Agent generates outputs. Humans decide whether to use them. No agent action on real systems.
Gate: >90% acceptance
Stage 02
Human review
Agent acts, but every action is reviewed and approved before execution. Full audit trail.
Gate: <2% override rate
Stage 03
Spot-check
Agent acts autonomously. A random sample is reviewed post-hoc. Escalation rules defined.
Gate: 3 months clean data
Stage 04
Full autonomy
Agent acts independently. Exception-based escalation only. Continuous monitoring in place.
Gate: proven + reversible
